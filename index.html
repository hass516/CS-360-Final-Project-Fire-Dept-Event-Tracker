Capstone Artifact

📱 Fire Department Event Tracker

The Fire Department Event Tracker is an Android mobile application created to help manage department events such as drills, meetings, parades, and training activities.


Technologies: Java, Android Studio, SQLite, RecyclerView, Material 3


Enhancement Category: Software Design and Engineering


  • Material 3 user interface redesign
  • Dark mode support
  • Improved input validation
  • Event time scheduling support
  • RecyclerView event card improvements
  • SQLite schema update for event time storage
  • Reusable helper methods and improved maintainability
