# Fire Department Event Tracker

## Application Overview

The Fire Department Event Tracker mobile application was designed to help fire department personnel manage and organize departmental events such as training sessions, meetings, and drills. The goal of the application was to provide a centralized and user-friendly system that allows users to create, edit, view, and delete event records while maintaining data persistence through a local database.

This application was developed using Java in Android Studio and utilizes SQLite for local data storage. The app also includes user authentication functionality, allowing users to create accounts and securely log into the system.

---

## User Needs and UI Design

The application was designed with simplicity and usability in mind. Fire department personnel often work in fast-paced environments where quick access to information is important. Because of this, the interface was designed to be clean, straightforward, and easy to navigate.

The login screen provides a simple authentication process with clearly labeled fields and buttons. The event management screens were designed to allow users to quickly add, edit, and remove events without unnecessary complexity. Throughout the application, consistency in layout and navigation was prioritized to improve the overall user experience.

---

## Development Process and Coding Approach

When developing the application, I approached the project by first identifying the core functionality that the system needed to support. I broke the project into smaller components, such as user authentication, database management, event creation, and event display functionality.

I used object-oriented programming principles to organize the application into multiple classes, including activities, adapters, models, and database helper classes. This helped keep the project more organized and easier to maintain. I also relied heavily on incremental testing throughout development to ensure that each feature functioned properly before moving on to the next component.

---

## Testing and Debugging

Testing was one of the most important parts of the development process. I tested the application frequently while building it to ensure that functionality such as user login, event creation, and database operations worked correctly.

This process helped identify issues related to data handling, navigation between activities, and user input validation. Debugging these issues improved the stability and reliability of the application while also helping me better understand the importance of testing throughout software development.

---

## Challenges and Problem Solving

One of the biggest challenges during development was managing the interaction between the application and the SQLite database. Ensuring that data was stored, retrieved, updated, and deleted correctly required careful planning and testing.

Another challenge was designing a user interface that was both functional and easy to use. I learned the importance of balancing functionality with simplicity to create a more user-centered experience.

---

## Successful Components

One area where I believe I was particularly successful was implementing the database functionality and overall application structure. The use of SQLite allowed the application to persist event information locally, and the organization of the application into separate components helped improve readability and maintainability.

This project helped strengthen my understanding of mobile application development, object-oriented programming, database integration, and software testing practices.
